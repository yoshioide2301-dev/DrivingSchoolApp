# AI_WORKFLOW.md

本プロジェクトの基本的な開発ワークフローを記録する。

## 基本フロー

```
ChatGPT
  ↓
正式な実装指示書
  ↓
Claude Code
  ↓
人間による承認
  ↓
実装
  ↓
テスト
  ↓
レビュー
  ↓
commit / push
```

## 各ステップの役割（現時点の想定）

1. **ChatGPT**
   - 企画・要件整理・仕様の検討を行う
2. **正式な実装指示書**
   - 上記の検討結果を、実装可能な形の指示書としてまとめる
3. **Claude Code**
   - 指示書に基づいて実装作業を行う
4. **人間による承認**
   - 実装内容・方針を人間が確認し、次に進めてよいか判断する
5. **実装**
   - 承認された内容に基づいてコードを作成・修正する
6. **テスト**
   - 動作確認を行う
7. **レビュー**
   - 実装内容・コード品質・仕様との整合性を確認する
8. **commit / push**
   - レビュー完了後、人間の指示のもとで commit / push を行う

## 運用ルール

- 各ステップを飛ばして先に進めない
- 「人間による承認」より前の段階で commit / push は行わない
- 指示書にない機能を先回りして実装しない
- ZeroNavi 等、別プロジェクトのリソースは本フローの対象外であり、混在させない
