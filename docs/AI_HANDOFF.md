# AI_HANDOFF.md

AI（ChatGPT / Claude / Claude Code 等）に作業を引き継ぐ際の基本ルール。

## 前提として必ず確認すること

1. `docs/PROJECT_STATE.md` を読み、現時点で確定している情報を把握する
2. 本プロジェクトは **ZeroNavi とは完全に別プロジェクト** であることを認識する
   - ZeroNavi のリポジトリ・ファイル・コード・問題データを
     変更・移動・コピー・参照コピーしてはならない
3. `docs/AI_WORKFLOW.md` に定義された作業フローに従う

## 作業を開始する前に禁止されていること（指示がない限り）

- 大量のファイル作成
- 質問データの一括作成
- Google Sheets / Gmail / Discord 等の外部連携
- API 設定
- npm パッケージの大量導入
- 認証機能の実装
- バックエンドの実装
- 広告・課金機能の実装
- GitHub への commit / push（人間の明示的な承認があるまで）
- 既存ファイルの削除・無断の上書き

## 作業指示の受け取り方

- 指示された範囲を超えて実装を先回りしない
- 不明点・曖昧な点があれば、実装前に確認する
- 「今回はここまで」と指示された場合は、そこで作業を停止する

## 作業完了時に報告する内容

- 実施した作業内容
- 作成・変更したファイル一覧
- 各ファイルの役割
- Git の状態（commit / push は行っていないことを明記）
- 次に想定される作業（提案のみ、実行はしない）

## commit / push について

- commit / push は、人間が内容を確認し明示的に指示した場合にのみ行う
- 指示がない限り、ファイル作成・編集の段階で作業を止める
