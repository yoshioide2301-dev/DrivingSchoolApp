# AI戦略司令室：新チャットの再開入口
2026-10-04／全PJ共通。新チャット・圧縮後は、まずこの短い入口を実読込する。

## 最初の応答から適用
- GPTの応答は冒頭と末尾に実際の状態を表示する。進捗は「🟢実行中（GPT）」、依頼完了は「✅完了（GPT）」。
- 本人の具体的な回答・操作・承認が必要なら「🔴確認待ち（あなた）」と次の行動を示す。次の依頼範囲を指定してもらう場合だけ「🔴指示待ち（あなた）」。
- 観測した障害は「⏸停止中（GPT）」＋理由・再開条件。最終回答に実行中を残さない。実行していないバックグラウンド処理を実行中と表示しない。
- 手動共有の単一REPORTは「＝＝＝PowerShell 【PJ名】 作業名　START M月d日（曜）HH:mm＝＝＝」から同じツール名・PJ名・作業名のENDまで。ツール名・PJ名・作業名は全て必須。実際の開始／終了の月日・日本語曜日・時刻を日本時間で表示し、年・UTCオフセットを含む日時も本文へ残す。通常エラーでもENDを出す（強制終了・電源断は保証外）。
- Claude本文をPowerShell REPORTへ含める場合は入れ子の区切りを作らない。Claude回答だけを別共有するときは「＝＝＝Claude 【PJ名】 作業名　START M月d日（曜）HH:mm＝＝＝」と同じ名称・実終了日時のENDで囲む。
- これらは新チャットでも初回から継承する。規則の登録、ランナーへの実装、Windows現物への反映、実行確認を区別する。

- 教材検査の報告は問題IDだけでなく、設問文・該当箇所・理由と根拠・修正前後・反映状態を示す。まず読む報告書を指定する（正式ルールM-1章）。

## 必要な正式資料
- 詳細・承認境界：[正式運用ルール](AI戦略司令室_運用ルール_20260927.md)。結果表示はO/Q章、教材検証はM/N章。
- 長い作業の整理：[CONTEXT-MANAGEMENT.md](CONTEXT-MANAGEMENT.md)。該当時のみ読む。
- ミチト教材の保存状態：[チェックポイント](checkpoints/MICHITO-QA-001-20261004.md)。アプリ全体の最新状態と混同しない。
- 各PJの実状態は対象repo・STATUS等で確認する。古い引継ぎ文の状態を現在状態として採用しない。

## 引継ぎ資料を作るとき
先頭にこの入口へのリンクと「応答の冒頭・末尾の状態表示、単一REPORTのツール名・PJ名・作業名付きSTART/ENDと実際の開始／終了の月日・曜日・時刻（日本時間）を初回から適用」を残す。全文ルールや過去ログをコピーせず、現状・承認範囲・未確認事項・次の担当と根拠参照を渡す。
入口を取得できない場合は、未読のまま継承確認済みと報告しない。
