## 審査説明案
Michito is an independent study app for the Japanese provisional driving licence written examination. It includes 200 original true/false practice questions, explanations, daily ten-question practice, a fifty-question thirty-minute mock exam, incorrect-answer review and a chart of the user's actual mock-exam scores. No account is required for learning. Learning content is bundled with the app; learning history and preferences are stored on the device. Optional feedback and surveys are sent only with consent. Internet access is required for these submissions. The owner-only support administration page is not a learner feature. Please test daily practice, mock-exam scoring, review and history from the home screen. [Confirm all behaviours against the signed build before submission.]
